# سایت هلدینگ (۵ زیرمجموعه)

سایت معرفی هلدینگ با Next.js 15 (App Router)، TypeScript، Tailwind CSS 4 + shadcn/ui، Framer Motion، GSAP ScrollTrigger، Lenis و React Three Fiber.
زبان سایت فارسی و راست‌به‌چپ (`lang="fa" dir="rtl"`) با فونت Vazirmatn است.

> نام «هلدینگ آوند»، زیرمجموعه‌ها و همه محتوا **نمونه** هستند. همه را از **پنل مدیریت** (`/admin`) ویرایش کنید.

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint
npm run typecheck
```

متغیر محیطی: `NEXT_PUBLIC_SITE_URL` (آدرس نهایی سایت، برای canonical، sitemap و Open Graph) — نمونه در `.env.example`.

## پنل مدیریت

آدرس: `https://دامنه-شما/admin`

**اولین ورود:** تا وقتی هیچ مدیری تعریف نشده، صفحه `/admin` فرم «ساخت حساب مدیر» را نشان می‌دهد. بلافاصله بعد از نصب وارد شوید و حساب بسازید؛ پس از آن این فرم غیرفعال می‌شود.

**امکانات:**

| بخش | چه کاری می‌توان کرد |
| --- | --- |
| داشبورد | تعداد محتواها، آخرین پیام‌ها و رزومه‌ها |

نکته‌ها:

- تصاویر بارگذاری‌شده خودکار به WebP تبدیل و در صورت نیاز کوچک می‌شوند (حداکثر عرض ۲۴۰۰ پیکسل).
- رزومه‌ها فقط PDF و Word تا ۵ مگابایت پذیرفته می‌شوند و فقط مدیر وارد شده می‌تواند دانلودشان کند.
- «نامک» زیرمجموعه‌ها، پروژه‌ها و اخبار در آدرس صفحه است و بعد از ساخت قابل تغییر نیست.
- در فرم‌ها `Ctrl+S` ذخیره می‌کند و اگر تغییرات ذخیره‌نشده داشته باشید، مرورگر قبل از خروج هشدار می‌دهد.

**فراموشی رمز عبور** (روی سرور، داخل پوشه پروژه):

```bash
npm run admin:password -- admin رمز-جدید
```

### داده‌ها و پشتیبان‌گیری

همه داده‌ها در پوشه `storage/` است (در گیت نیست و با `git pull` دست نمی‌خورد):

- `storage/holding.db`: پایگاه داده SQLite (محتوا، پیام‌ها، رزومه‌ها، مدیران)
- `storage/uploads/`: تصاویر بارگذاری‌شده
- `storage/resumes/`: فایل‌های رزومه

برای پشتیبان‌گیری کافی است از کل پوشه `storage/` نسخه بگیرید. با متغیر `STORAGE_DIR` می‌توانید مسیر آن را عوض کنید. اولین اجرا پایگاه داده را با محتوای نمونه `lib/content/data.ts` پر می‌کند.

> چون داده روی دیسک سرور ذخیره می‌شود، سایت باید روی سروری با دیسک پایدار اجرا شود (مثل VPS اوبونتو). Vercel و سرویس‌های serverless مناسب نیستند.

## تصویر سایت زیرمجموعه‌ها

تصاویر فعلی **نمونه** هستند. برای هر شرکت:

1. از سایت واقعی یک **اسکرین‌شات تمام‌صفحه** (Full-page) با عرض ۱۴۴۰ پیکسل بگیرید؛ مثلاً در Chrome: DevTools ← `Ctrl+Shift+P` ← «Capture full size screenshot».
2. در پنل: زیرمجموعه‌ها ← شرکت مورد نظر ← «تصویر وب‌سایت» ← بارگذاری، و آدرس «وب‌سایت» را وارد کنید.

هر ارتفاعی قابل قبول است: تصویر داخل قاب مرورگر به اندازه طول صفحه اسکرول می‌شود. اگر شرکتی وب‌سایت ندارد، فیلد وب‌سایت را خالی بگذارید تا دکمه «وب‌سایت» نمایش داده نشود.

## سه‌بعدی و عملکرد

- همه مدل‌ها **رویه‌ای (procedural)** هستند و هیچ فایل glb دانلود نمی‌شود. برای مدل واقعی از `useGLTF` با فایل فشرده (Draco/Meshopt، زیر ۱.۵MB) استفاده کنید.
- Three.js فقط وقتی دانلود می‌شود که صحنه نزدیک viewport باشد (`next/dynamic` + IntersectionObserver). خارج از دید، رندر متوقف می‌شود (`frameloop="never"`).
- سه سطح کیفیت (`hooks/use-3d-quality.ts`):
  - `full`: دسکتاپ
  - `lite`: موبایل/دستگاه ضعیف — اشیای کمتر، DPR پایین، بدون antialias
  - `off`: بدون WebGL، `prefers-reduced-motion` یا Data Saver — fallback دوبعدی
- LOD با `Detailed`، و `PerformanceMonitor` / `AdaptiveDpr` برای تنظیم خودکار DPR.

## دسترس‌پذیری

- `prefers-reduced-motion`: Lenis، cursor سفارشی، اسکرول افقی pin‌شده و صحنه‌های ۳D غیرفعال می‌شوند. Framer Motion با `MotionConfig reducedMotion="user"` تنظیم شده است.
- لینک «پرش به محتوا»، `aria-current` در ناوبری، بستن منوی موبایل با Escape. Canvasها `aria-hidden` هستند و هر لینک داخل صحنه ۳D معادل HTML قابل دسترس دارد.
- SplitText متن فارسی را **کلمه‌به‌کلمه** تقسیم می‌کند (نه حرف‌به‌حرف) تا اتصال حروف حفظ شود.

## Deploy

روی سرور اوبونتو با Node.js 22 (نسخه ۲۲.۱۳ یا جدیدتر، به‌خاطر SQLite داخلی Node):

```bash
npm ci && NEXT_PUBLIC_SITE_URL=https://example.com npm run build && npm start
```

پوشه `storage/` را در به‌روزرسانی‌ها حذف نکنید.
